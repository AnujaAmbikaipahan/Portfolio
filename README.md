# Anuja Ambikaipahan — Digital Portfolio

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and folders** in this project.
3. Make sure `assets/profile.jpg` is uploaded — this is why the photo works on GitHub.
4. Go to **Settings → Pages**.
5. Select the branch containing `index.html` and save.
6. GitHub will publish the portfolio.

### Important
Do NOT use a Windows path such as:
`C:\Users\Anuja\Desktop\Anuja`

The website uses the relative path:
`assets/profile.jpg`

Relative paths work after uploading the whole project to GitHub.
